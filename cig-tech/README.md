# cig-tech

Custom Intelligence Group theme for the Claude desktop app. A dark navy and cyan look with an animated circuit board background (drifting grid, traces with data pulses, blinking nodes, scanline) and a glowing CIG logo.

Install: run `claude --plugin-dir <path to this folder>` or set `CLAUDE_CODE_PLUGIN_DIRS` to this folder's absolute path. It only draws in the desktop and mobile apps, not the terminal.
